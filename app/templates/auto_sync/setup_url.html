Step 1 — Upload your Excel file to the cloud

Google Drive:

  1. Upload .xlsx file
  2. Right-click file → Share
  3. Change to "Anyone with the link can view"
  4. Copy the link (should contain /file/d/...)

OneDrive:

  1. Upload .xlsx file
  2. Right-click → Share → "People you choose"
  3. Change to "Anyone with the link can view"
  4. Copy link

Dropbox:

  1. Upload .xlsx file
  2. Right-click → Share → Copy link

💡 The file must be publicly readable. The CRM will fetch it on your chosen schedule and sync any changes into Contacts automatically.

Paste the share link for your .xlsx file.
